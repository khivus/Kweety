# Kweety

Расширитель текста и инструменты ввода для Windows на AutoHotkey v2. Интерфейс на русском языке. Версия 0.4.2. Горячие клавиши по умолчанию не назначены; при желании задайте их в «Горячих клавишах».

Если при запуске Kweety не может прочитать или применить настройки, он показывает причину и запускается с настройками по умолчанию. Прежний файл с настройками и шаблонами переносится в `settings.ini.reset-*.ini` в папке настроек. Для сброса при запуске вручную выполните `Kweety.exe --reset-config` или запустите скрипт командой `AutoHotkey64.exe Kweety.ahk --reset-config`.

Пункт меню трея показывает текущее состояние и действие: «Замена включена — выключить» либо «Замена выключена — включить». Во включённом состоянии он также отмечен галочкой. Текст и подсказка значка обновляются при переключении как из трея, так и из главного окна, а при запуске отражают сохранённое состояние.

В 0.2.0 добавлены горячие клавиши исправления раскладки и регистра, программы-исключения, меню шаблонов с поиском, поиск в главном списке, импорт Punto и редактор с цветом/жирным/курсивом/подчёркиванием. **[Инструкция по новым функциям и проверки](docs/FEATURES.md)**. Форматированные шаблоны вставляются через HTML/RTF-буфер при включённом Ctrl+V; при отключённом — обычным текстом без оформления. Результат оформления зависит от поддержки в приложении назначения.

## Запуск

Основной вариант — скрипт `Kweety.ahk`, для которого не требуется подпись собственного EXE. Установите AutoHotkey v2, распакуйте `dist\Kweety-ahk.zip` целиком в постоянную папку и дважды щёлкните `Kweety.ahk`. Папки `lib` и `assets` должны оставаться рядом со скриптом. Из исходной папки проекта можно запускать тот же `Kweety.ahk` без сборки. Ограничения Windows или организации на запуск скриптов при этом продолжают действовать.

Закрытие окна сворачивает программу в системный трей. Для завершения выберите «Выход» в меню значка. Параметр `--background` запускает приложение сразу в трее.

Флажок «Запускать при входе в Windows, свернув в трей» включает автозапуск для текущего пользователя. При следующем входе Kweety запускается сразу значком в трее, без главного окна. Снятие флажка отключает автозапуск. По умолчанию автозапуск выключен. Сначала сохраните скрипт с папками `lib` и `assets` в постоянной папке: ярлык ссылается на текущий файл программы. После запуска новой версии путь уже включённого автозапуска обновляется на неё.

Автозапуск реализован ярлыком `Kweety.lnk` в папке автозагрузки текущего пользователя (`shell:startup`) с аргументом `--background`. Для исходника ярлык запускает текущий интерпретатор AutoHotkey v2 с путём скрипта в кавычках. Права администратора не требуются. Настройка определяется наличием ярлыка и не дублируется в INI-файле шаблонов.

## Как пользоваться

1. По умолчанию уже добавлен шаблон: `fff` / `ааа` → `тестовый текст`.
   При импорте Punto этот стандартный шаблон удаляется; изменённый вами текст или оформление сохраняются.
2. Наберите сокращение отдельным словом в другом приложении и нажмите Пробел или Enter. Сокращение заменится, клавиша замены поглотится. После совпавшего сокращения Enter не отправляется приложению.
3. В верхней части окна выберите любые сочетания клавиш Пробел, Enter и Tab. Нужна хотя бы одна клавиша. Не выбранные клавиши работают в приложении обычным образом.
4. Нажмите «Добавить», введите сокращение и полный текст. Enter в редакторе создаёт новую строку. По умолчанию весь текст вставляется целиком вместе с переносами: клавиши Enter не отправляются.
5. Выберите строку и нажмите «Изменить» либо дважды щёлкните по ней. Для удаления предусмотрено подтверждение. Несохранённые изменения тоже требуют подтверждения закрытия.
6. Отключите флажок «Замена сокращений включена» или приостановите замену через меню трея.
7. «Вставлять весь текст целиком (Ctrl+V)» включено по умолчанию: и однострочный, и многострочный шаблон вставляется одной командой Ctrl+V. Если программа не поддерживает вставку или нужны именно события Shift+Enter, отключите флажок для отправки клавиш. Этот режим медленнее и зависит от обработки каждого символа приложением.

Соответствие раскладок автоматическое, для стандартных английской QWERTY и русской ЙЦУКЕН. Например, `ghbdtn` и `привет` вызывают один шаблон. Регистр сокращения не влияет на результат; регистр подставляемого текста сохраняется. Совпадения между шаблонами, включая другую раскладку, запрещены. Сам редактор Kweety исключён из замены.

До 1000 шаблонов, до 50 000 символов в каждом. Текст вставляется буквально: `{Enter}`, `!`, `^`, `+`, `#` не превращаются в команды. Вставка сокращения из буфера не считается его набором.

В режиме Ctrl+V прежнее содержимое буфера обмена (включая нетекстовые форматы) сохраняется перед подстановкой и восстанавливается таймером через 2 секунды после Ctrl+V. Перед вставкой приложение получает короткую паузу для обработки удаления сокращения. Если за это время вы скопировали что-то новое, Kweety оставляет новую копию. Следующие подстановки до восстановления сохраняют исходный буфер.

Длина текста, переносы строк и Tab больше не переключают программу на посимвольный ввод. Все строки, включая пустые и завершающие, помещаются в один текстовый элемент буфера обмена. Нет отдельных вставок по строкам или пауз между ними. Переносы нормализуются в CRLF для Windows. При занятом буфере программа делает до пяти попыток; если буфер всё ещё недоступен, оставляет сокращение на месте и показывает уведомление; скрытого перехода на медленный посимвольный ввод нет.

## Данные

Настройки сохраняются сразу после изменений в `%APPDATA%\Kweety\settings.ini`. Предыдущая сохранённая версия находится в `settings.ini.bak`. «Папка настроек» открывает эту папку. Переносите файл настроек для переноса шаблонов. Это локальные данные без шифрования; шестнадцатеричное кодирование текста служит для надёжного хранения многострочных значений.

При повреждении конфигурации запуск прекращается с сообщением; исходный файл не перезаписывается. Для восстановления закройте программу, скопируйте `.bak` поверх `.ini` и запустите снова. Для сброса переименуйте `.ini`. Настройки сохраняются независимо от папки расположения EXE.

## Сборка и проверки

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Нужен AutoHotkey v2 x64 в `C:\Program Files\AutoHotkey`; другой путь передаётся через `-AhkRoot`. Скрипт запускает тесты ядра и функций, проверяет старт исходника и создаёт `dist\Kweety-ahk.zip` со скриптом, библиотеками, иконкой и документацией. Компилятор и подпись для этого не нужны. Тесты создают и удаляют только собственную временную конфигурацию. `--smoke-test` проверяет создание главного окна и регистрацию сокращений, не отправляя клавиши.

При необходимости `powershell -ExecutionPolicy Bypass -File .\build.ps1 -CompileExe` дополнительно собирает `dist\Kweety.exe` с иконкой и проверяет его запуск. Только для этой опции нужен Ahk2Exe. EXE работает без установки AutoHotkey; сборка не подписывает его.

Используются штатные [динамические hotstring](https://www.autohotkey.com/docs/v2/lib/Hotstring.htm) AutoHotkey с поглощением завершающей клавиши. При включённом Ctrl+V подстановка состоит только из удаления сокращения и одной команды вставки; никаких событий Enter не отправляется.

В режиме клавиш текст отправляется через SendEvent с задержками обычных клавиш и короткими паузами между пакетами до 128 символов. Unicode и пары суррогатов сохраняются. Tab передаётся как текстовый символ, а не команда перехода к следующему полю. При смене активного окна отправка останавливается перед следующим пакетом. Скорость зависит от приложения, принимающего текст.

## Проверить вручную перед использованием в переписке

Автоматические тесты покрывают сопоставление раскладок, конфликты, буквальный текст, план отправки переносов, сохранение длинных Unicode-текстов и ошибки конфигурации. Реальный ввод и внешний вид окон требуют ручной проверки:

- В Блокноте наберите `fff` + Пробел и `ааа` + Enter в соответствующих раскладках. Оба раза ожидается исходная тестовая фраза без дополнительного пробела или переноса. Повторите с `FFF` и после исправления сокращения Backspace.
- Включите только Tab: `fff` + Tab должен замениться без перехода фокуса; Пробел и Enter должны работать обычно. Проверьте другие сочетания флажков; отключение последней клавиши должно быть отклонено.
- Создайте шаблон из нескольких строк с пустой строкой и символами `{Enter} !^+#`. При включённом Ctrl+V проверьте в черновике вашего мессенджера: все строки должны вставиться одной командой, символы и пустые строки — сохраниться, сообщение не должно отправляться. Не используйте важный чат для первой проверки.
- Добавьте, измените и удалите шаблон; попробуйте создать второй с сокращением в противоположной раскладке. Ожидается предупреждение о совпадении. Отмените изменения в редакторе и проверьте подтверждение.
- Перезапустите Kweety: шаблоны, выбранные клавиши и пауза должны сохраниться. Проверьте значок трея, сворачивание, повторное открытие и выход.
- Убедитесь, что «Пробел», «Enter» и «Tab» стоят в одной строке в этом порядке. Переключите каждый флажок, затем перезапустите приложение: выбранные клавиши должны сохраниться.
- Включите автозапуск и перезапустите приложение: флажок должен остаться включённым. Выйдите из Windows и войдите снова: должен появиться значок Kweety в трее без главного окна. Откройте окно двойным щелчком по значку и проверьте замену сокращения.
- Снимите флажок автозапуска и повторно войдите в Windows: приложение не должно запуститься автоматически. Ручной запуск EXE по-прежнему должен открывать главное окно. Запуск с `--background` должен оставлять только значок трея.
- Наберите сокращение внутри более длинного слова: замены быть не должно. Проверьте набор в самом редакторе Kweety, смену окна и щелчок мышью между частями сокращения; они не должны вызывать случайную замену.
- Проверьте интерфейс при вашем масштабе Windows и длинных текстах: подписи должны читаться, редактор и список — прокручиваться.
- Включите «Вставлять весь текст целиком (Ctrl+V)» и проверьте однострочный и многострочный шаблоны в черновике Discord, включая ваш прежний шаблон с четырьмя переносами. Ожидается одна вставка всего текста без набора по буквам и отдельных команд для строк. Затем отключите флажок и проверьте режим клавиш: переносы должны быть Shift+Enter без отправки сообщения.
- Перед быстрым шаблоном скопируйте текст или изображение; через секунду проверьте вставку прежнего содержимого в подходящую программу. Повторите две подстановки подряд: исходный буфер должен сохраниться. Если успеть скопировать новый текст после шаблона, Kweety не должен заменять его старым буфером.
- Проверьте шаблон длиннее 1000 символов с включённым Ctrl+V: весь текст, включая конец, пустые строки и Tab, должен вставиться целиком. Повторите с отключённым Ctrl+V: начало, конец и переносы должны сохраниться без обрезания, но возможна задержка обработки клавиш. Перезапустите приложение и проверьте сохранение выбранного режима.

Вставка Ctrl+V и Shift+Enter обрабатываются каждым приложением самостоятельно. Приложение может ограничивать длину вставляемого текста или показывать отдельное окно для слишком большой вставки. В некоторых программах и играх синтетический ввод не поддерживается; приложения, запущенные от администратора, могут не принимать ввод от обычного процесса. При отсутствии совпадения Enter остаётся обычным Enter. Kweety — расширитель текста; автоматического исправления раскладки произвольных слов в этой версии нет.

## Размер окон и сочетания клавиш

Все окна Kweety можно растягивать и разворачивать: списки, редактор текста и поле исключений используют свободное место, а кнопки остаются внизу. Минимальный размер защищает элементы от перекрытия. Диалоги выбора файла и цвета используют стандартное поведение Windows.

В «Горячих клавишах» нажмите поле команды и нажмите нужное сочетание на клавиатуре. Esc отменяет запись, «Очистить» отключает команду. Для букв нужны Ctrl, Alt или Win; F1–F24 доступны отдельно. Одинаковые сочетания для разных команд запрещены. Отдельная команда «Инвертировать регистр» меняет каждую букву: `аБв → АбВ`; команда верхнего/нижнего регистра сразу переводит текст в верхний регистр, а полностью прописной — в нижний.

Если вставка в Mail.ru нестабильна, отключите Ctrl+V: теперь этот режим отправляет обычный текст даже для форматированных шаблонов. Оформление хранится в шаблоне и снова используется после включения Ctrl+V. Проверка в реальном Mail.ru обязательна; синтетический ввод зависит от браузера и редактора. Чек-лист: [MANUAL-VERIFICATION.md](docs/MANUAL-VERIFICATION.md).


Оформление включается отдельно для каждого шаблона флажком «Использовать оформление» и по умолчанию выключено, в том числе у шаблонов из старых настроек. Цвет и начертание сохраняются при отключении флажка. При включении они отображаются в столбце текста и вставляются в режиме Ctrl+V.

Форматированный предпросмотр показывает переносы как ` ↵ `, сохраняя оформление и текст следующих строк в той же строке таблицы. Горячие клавиши преобразования не требуют отпускать Ctrl/Alt/Shift/Win перед выполнением.


## Мгновенная замена и история буфера

«Сразу после последнего символа сокращения» включает замену без Пробела, Enter или Tab. Эти три флажка становятся неактивными; их выбор сохраняется для возвращения к обычному режиму. Сокращение по-прежнему должно начинаться отдельным словом. Если одно сокращение является началом другого, короткое сработает первым.

В главном окне отдельные кнопки «Горячие клавиши» и «Исключения». В окне горячих клавиш есть три независимых назначения для истории буфера: укажите номер 1–20 и запишите сочетание. Например, номер 2 — предпоследняя копия, номер 3 — третья с конца. Чтение/вставка не меняет порядок истории, поэтому эти сочетания можно нажимать последовательно. История хранит до 20 копий в оперативной памяти (до 16 МБ каждая), включая изображения и оформление; после выхода очищается. При запуске доступное содержимое буфера становится первой записью, затем добавляются новые копии. Старые записи Win+V не загружаются. Собственные вставки Kweety и восстановление буфера не добавляются в историю. В исключённых приложениях сочетания не действуют, но копирование по-прежнему пополняет историю.

Проверка: включите мгновенную замену и наберите сокращение без завершающей клавиши; выключите её и проверьте возврат сохранённых флажков. Назначьте разные сочетания для номеров 2 и 3, скопируйте по очереди A, B и C, затем вставьте вторую и третью записи: ожидаются B и A. Повторите с изображением и форматированным текстом. Проверьте сохранение назначений после перезапуска и независимое сохранение исключений.

В режиме Ctrl+V удаление сокращения и команда вставки отправляются одним пакетом SendInput, без паузы между ними. Отрисовка результата зависит от приложения назначения. Режим клавиш сохраняет задержки для совместимости.
