# Исследование миграции Punto Switcher

В стандартных установках пользовательские данные располагаются в `%APPDATA%\Yandex\Punto Switcher\User Data`; встречается прежний каталог `3.0`. В портативных сборках путь может отличаться — файл можно выбрать вручную. Настройки находятся в `preferences.xml`, сокращения — в `replace.dat`. На данном компьютере стандартные каталоги Punto при проверке не обнаружены, поэтому собственный файл пользователя не проверялся.

## replace.dat

Реализован формат PSRF по [первичному описанию и рабочему декодеру автора исследования](https://www.programmersforum.rocks/t/punto-switcher-replace-dat/5448/20). После сигнатуры следуют записи: 32-битная длина, байт флага и две UTF-16LE-строки с нулевыми окончаниями. Данные строк XOR-кодированы последовательностью генератора с фиксированным начальным состоянием. Импортёр проверяет границы, длины и наличие ровно двух строк. Неизвестная сигнатура и оборванные записи отклоняются целиком.

Байт флага не переносится: его назначение не установлено. Глобальные параметры замен читаются отдельно из XML. Тестовый файл `tests/fixtures/punto-replace.dat` независимо сформирован в PowerShell из собственных демонстрационных строк и проверяет Unicode и переносы. Из сторонних файлов пользовательские тексты в проект не копировались.

## preferences.xml

Имена совместимых полей подтверждены [опубликованным примером XML в исследовании Dr.Web](https://vms.drweb.com/virus/?i=25907382): `ReplaceOnSpace`, `ReplaceOnEnterAndTab`, `RunAtStartup`, `ProgramsExceptions`. Первые два задают клавиши замены; Enter и Tab в этом варианте формата объединены. Поддерживается обычный текстовый список EXE, разделённый точкой с запятой, запятой или переводом строки. Сложные/бинарные варианты исключений не угадываются.

XML загружается через MSXML6 с запрещёнными DTD и внешними сущностями. Автозапуск переносится только отдельным выбором в предпросмотре и создаёт ярлык Kweety, а не запускает Punto. Другие параметры не подменяются приближёнными аналогами.

## Ограничения

Импорт Windows PSRF не заявляет поддержку всех версий и платформ Punto. Горячие клавиши Punto хранятся как числовой массив с неустановленным соответствием команд; он не импортируется. Дневник, словари автопереключения, бинарные программы-исключения и заголовки окон также не переносятся. Всё перечислено в интерфейсе до подтверждения импорта.
